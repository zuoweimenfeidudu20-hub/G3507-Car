软件四层体系结构

第 4 层：业务决策与模式调度层 (Application Layer) init.c / key.c

主循环轮询按键状态机，根据选定模式（普通、特殊路段、摆动循迹）激活对应逻辑；管理系统急停与状态复位。

第 3 层：运动控制与状态机算法层 (Control & Algorithm Layer) grayscale_sensor.c / pid_motor.c

转向外环： 8路灰度加权误差解算、岔路/台阶/丢线状态机识别、转向校正 PID。
速度内环： 10ms 中断触发增量/位置式 PID 计算，双电机目标计数值与实际计数值闭环。

第 2 层：设备与传感器驱动层 (Device Drivers) motor.c, JY901P.c, hcsr04.c, uart.c

封装具体硬件行为：电机正反转及 PWM 占空比钳位输出、超声波测距定时触发与脉宽换算、JY901P 串口协议校验解包、遥测串口帧打包。

第 1 层：硬件抽象与外设库 (TI DriverLib / SysConfig HAL) ti_msp_dl_config.c / .h

由 TI SysConfig 工具全自动生成，配置 GPIO、TIMA0/A1、TIMG0/6/7/8、UART0/1、I2C0 与 ADC0 底层时钟分频与中断向量。

双闭环运动控制数据流

① 转向环 (外环)
输入: 8路灰度传感器加权
error = sum(wi) / cnt
输出: correction (偏航校正)
② 差速分配器
基准: base_pwm = 35%
左轮: pwm + correction
右轮: pwm - correction
③ 速度闭环 (内环 10ms)
定时器: TIMG0 周期中断
反馈: 4倍频实际脉冲数
输出: 电机驱动 PWM 占空比

PID 控制器特性：

  • 方向换向清零： 当目标方向反号时，自动重置积分项与历史误差，防止反向冲冲超调。
  • 双重限幅与抗积分饱和： 积分项严格限制在 [-integral_limit, integral_limit] 之间；在输出已达到 100% 极限且误差继续同向增大时，冻结积分累加。

寻迹路径识别与动作状态机

地图路况特征识别 (trackpattern)

  • pattern_line 正常巡线，黑线在中心传感器附近
  • pattern_rightbranch 右侧传感器识别到分支路线
  • pattern_leftbranch 左侧传感器识别到分支路线
  • pattern_r90 直角弯道模式
  • pattern_lost 全白丢线（cnt=0），保持方向并启动 2s 倒计时

小车执行状态转移 (trackstate)

state_line ──(连续3次右分支)──> state_c_lockright (锁定右转)
state_c_lockright ──(左外踩线)──> state_stair1 (台阶循迹)
state_stair1 ──(中间黑变白)──> state_teshu_lockleft1 (锁定左转)
state_line ──(丢线累计 >200 ticks)──> state_stop (刹车急停)

💡 状态迁移均引入了 track_confirm(cond, req) 多周期连续检测滤波，防止瞬态反射造成误切。
